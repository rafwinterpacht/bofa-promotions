# Dynamic features plan — promotions.bankofamerica.com

## Phase D1 — delivered with the archetypes (self)
- **Offer-term modals (M, modal-loader).** The six experience fragments are delivered as EDS pages at their source paths (/content/experience-fragments/consumer_marketing/en/offers/t3-dda/…); links with those hrefs on the offer page open the fragment's content in a dialog (a `modal` widget in scripts: fetch `<path>.plain.html`, render in <dialog>). Authoring contract: an author edits the fragment page; the offer page keeps a plain link. Verification: dynamics-check modal feature + content-presence on the fragment pages.
- **Exit notice / Advertising Practices modals (chrome).** Rebuilt in the header/footer runtime: off-site links show the "You are now leaving" notice with Continue / Cancel.
- **Client-rendered component copy (CR).** Authored as content from the settled DOM capture.

## Phase D2 — owner switches (interim tier ships now)
- **Martech.** `scripts/martech.js` generated by martech-scaffold from `stardust/martech-contract.json` with every part disabled. Owner sets enabled:true per part and re-runs the scaffold.
- **Spanish alternates.** Links stay absolute to the source.

Effort: D1 inside the archetype prototypes and the foundation; D2 owner-side configuration only.
